# Ride-Sharing-platform-project

## Abstract

This project presents a Ride Sharing Platform developed using C programming and Data Structures. The system efficiently manages drivers and passengers while optimizing ride allocation using graph-based techniques. By representing relationships through an adjacency matrix and applying a greedy matching algorithm, the platform minimizes travel distance and improves ride efficiency.



## Introduction

With the increasing demand for smart transportation systems, ride-sharing applications have become essential. This project simulates a simplified version of platforms like Uber and Ola by focusing on driver-passenger matching using core DSA concepts such as arrays, graphs, and greedy algorithms.

## Objectives
To design a ride-sharing system using C programming
To implement graph data structures for distance mapping
To optimize driver-passenger allocation using a greedy algorithm
To provide a menu-driven interface for user interaction

## Scope of the Project
